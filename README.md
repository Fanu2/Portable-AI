# Portable-AI

A portable, offline-first local AI toolkit designed to run from USB storage across Windows and Linux.

## Vision

Portable-AI provides a self-contained local AI environment where models, tools, and configuration can travel with the user.

## Architecture Principles

- Offline-first by default
- Provider-neutral AI runtime
- Model registry driven design
- Hardware-aware model selection
- Portable USB deployment
- Stable contracts before implementations
- User data separated from application assets
- Extensible without core redesign
